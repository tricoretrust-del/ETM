## v0.2 (2026-11-23): 확정이 없는 것은 미결 + 확인 요청

### 사용자 답

1. 포설규사는 판매하기도 하고, 출하량에 따라 무료로 주기도 한다. 무상 제공 여부를 묻고, 확정이 없으면 미결로 둔다.
2. 일반선형·일반점형은 고강도.선형·점형과 같다. 명칭을 통일한다.
3. 운반비는 계약 단가와 상황에 따라 다르다. 업체별 단가 기록과 함께 운반비 부담 조건을 묻고, 확정이 없으면 운반비의 채무 여부를 미결로 둔다.

### 구조 변화

- 돈 줄의 상태를 확정 / 미결로 하고 **미결 사유** 칸을 더했다. 새 표는 만들지 않았다.
- 조회 `confirmations`: 미결 줄마다 확인 요청 문장과 판단 근거를 만든다.

### 결과 (미결 = 확인 요청)

| 사유 | 줄 | 참고 금액 | 예 |
|---|---|---|---|

| 무상 제공 여부 | 173 | 31,270,000 | "2026-11-17 반석건업 수지씨엔에스 / 평택시 … 포설규사 12개를 출하했습니다. 무상 제공인가요, 판매인가요?" 근거: 같은 청구처의 최근 판매 단가 100,000원 |

## v0.3 (2026-11-23): 월 원가 조회, 운반비 한 번만

### 사용자 답

1. 출하처 이름은 **채무자 / 사업 / 하차지**로 확정.
2. **부자재 = 제품에 직접 들어가지 않는 모든 것.**
3. 관급 표시는 불필요하다. 거래처(채무자)에서 구분된다 → `project.kind` 칸을 뺐다.
4. 원가는 고정비·변동비·운영비로 조회해 계산한다(제품이 단순해서 가능). 뼈대는 '(공)운영비용|원가-지오블록' 시트의 월 탭이다. 단순하게.

### 새로 드러난 것: 운반비가 두 번 적혀 있었다

출고 탭의 운반비(송장별)와 비용 탭의 운송 줄(운송사별로 하루치를 묶어 적음)은 같은 운행이다. 2025-04 이후 달마다 합계가 거의 같다(예: 2025-06 5,890,000 / 5,890,000).

- 규칙: 비용 탭 운송 줄이 그달 출고 운반비의 절반 이상이면 그달은 비용 탭 줄(운송사 이름 있음)만 채무로 둔다. 2024-09 ~ 2025-03은 비용 탭에 운송 줄이 없어 출고 운반비를 쓴다.
- 결과: '운반비 운송사 미상' 501 → 153건. 2026-03·05에 '(상차)' 음수 운반비가 남아 있다.

### 월 원가 조회 (2025-06, 시트와 대조)

```
2025-06 지출 7,081만 원: 고정 412만 원, 변동 5,331만 원(원자재 4,081만 원), 운영 1,338만 원.
상품 매입 562만 원과 출하 운반비 589만 원을 빼면 생산 원가 5,930만 원.
생산 6,297㎡ → ㎡당 9,416원.
```

| | 시트 | ETM | 차이 |
|---|---|---|---|
| 고정 | 1,455만 | 412만 | 원가용 줄(급여·임금·4대보험·보험료·세금·차량임대) 1,043만 |
| 변동 | 5,906만 | 5,331만 | 원가용 줄(임금(변동) 439만, 소모품 102만) + 원자재 단가 차이 |
| 운영 | 1,341만 | 1,338만 | 일치 |
| 생산량 | 6,297 | 6,297㎡ | 일치 |

남은 차이는 모두 '원가용'(지출 수단 없이 원가에만 넣은 줄)이다. 대부분 인건비라 이관하지 않았다.
